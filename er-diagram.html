Beziehungen & Löschverhalten

Users 1 → * Specimens CASCADE User geloescht = Funde weg
Users 1 → * TaxonomyNodes SET NULL User geloescht = Vorschlag bleibt
TaxonomyNodes 1 → * Specimens RESTRICT Art mit Funden nicht loeschbar
TaxonomyNodes 1 → * TaxonomyNodes RESTRICT Parent-Child Hierarchie
GeographicLoc. 1 → * Specimens SET NULL Ort geloescht = Fund bleibt
GeographicLoc. 1 → * GeographicLoc. RESTRICT Parent-Child Hierarchie
Specimens 1 → * SpecimenImages CASCADE Fund geloescht = Bilder weg
Specimens 1 → * Loans CASCADE Fund geloescht = Ausleihen weg
Users 1 → * Loans (Lender) RESTRICT User mit Ausleihen nicht loeschbar
Users 1 → * Loans (Borrower) RESTRICT User mit Ausleihen nicht loeschbar
PK = Primary Key
FK = Foreign Key
UK = Unique
? = Optional (nullable)
CASCADE = wird mitgeloescht
RESTRICT = Loeschen blockiert
SET NULL = Referenz wird null
